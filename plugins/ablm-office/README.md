# 에이블램 에이전트OS 오피스 (ablm-office)

AI 직원 6명이 일하는 작은 사무실을 이 PC의 브라우저에서 여는 Claude Code / Codex 플러그인입니다. 대표님이 부탁하면 팀장 그레이스가 일을 나누고, 직원들의 말풍선과 결과물을 화면에서 확인할 수 있습니다.

설치와 사용법은 [공개 저장소 안내](https://github.com/Andrew-Aparche/ablm-office)를 따라 주세요. Node.js 20 이상, Mac 또는 Windows, Codex 데스크탑 앱 또는 Claude 데스크탑 앱의 Code 화면이 필요합니다.

- 설치: 앱의 **플러그인**에서 `Andrew-Aparche/ablm-office`를 추가하고 오피스를 설치한 뒤 **새 대화**를 엽니다.
- 첫 실행: **에이블램 오피스 열어줘**라고 보내고, 앱에 허락 창이 나오면 대표님이 직접 **허용**을 누릅니다. **항상 허용**은 이 오피스만 허락하는 선택지가 보일 때만 선택 사항입니다. 별도 연결 파일을 실행하지 않습니다.
- 열기: 새 대화에서 `/ablm-office` 또는 “에이블램 오피스 열어줘”. 이미 실행 중이면 같은 오피스를 다시 엽니다.
- 닫기: 대화에서 “오피스 닫아줘”. 브라우저 탭을 닫는 것만으로는 종료되지 않습니다.
- 오피스를 여닫는 `office` 도구는 open / status / close만 받습니다. 임의 셸 명령·외부 URL·파일 경로는 받지 않습니다.

도구가 안 보이면 **플러그인**에서 오피스가 켜져 있는지 확인하고 **새 대화**에서 다시 부탁해 주세요. 한 번 더 실행 허락을 요청하면 내용을 읽고 **이번만 허용**을 누릅니다. 조직에서 차단했다면 담당자에게 문의해 주세요.

Windows 앱의 전체 첫 실행과 Claude 앱의 사용자 지정 저장소 추가·실행은 실기 미검증입니다. 앱의 버전·언어에 따라 버튼 이름이 다를 수 있습니다.

이 플러그인은 오픈소스가 아닙니다. [LICENSE](https://github.com/Andrew-Aparche/ablm-office/blob/main/LICENSE)를 참고하세요.
