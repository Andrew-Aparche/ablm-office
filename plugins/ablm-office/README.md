# 에이블램 에이전트OS 오피스 (ablm-office)

AI 직원 6명이 일하는 작은 사무실을 이 PC의 브라우저에서 여는 Claude Code / Codex 플러그인입니다. 대표님이 부탁하면 팀장 그레이스가 일을 나누고, 직원들의 말풍선과 결과물을 화면에서 확인할 수 있습니다.

설치와 사용법은 [공개 저장소 안내](https://github.com/Andrew-Aparche/ablm-office)를 따라 주세요. Node.js 20 이상, Mac 또는 Windows, 로컬 Claude Code / Codex 사용 환경이 필요합니다.

- 열기: 새 대화에서 `/ablm-office` 또는 “에이블램 오피스 열어줘”. 이미 실행 중이면 같은 오피스를 다시 엽니다.
- 닫기: 대화에서 “오피스 닫아줘”. 브라우저 탭을 닫는 것만으로는 종료되지 않습니다.
- 오피스를 여닫는 `office` 도구는 open / status / close만 받습니다. 임의 셸 명령·외부 URL·파일 경로는 받지 않습니다.

이 플러그인은 오픈소스가 아닙니다. [LICENSE](https://github.com/Andrew-Aparche/ablm-office/blob/main/LICENSE)를 참고하세요.
